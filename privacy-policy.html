LEGAL

Privacy Policy

This is a student-built digital museum project. This page explains, plainly, what happens with data on this site — because the honest answer is "very little."

WHAT WE COLLECT

Browsing the museum — artifacts, timeline, exhibitions, the virtual museum, and learn pages — does not require an account and does not send any personal information anywhere. These pages read reference data (artifact records, exhibition records) from a database or a local file; nothing about you as a visitor is recorded.

"MY COLLECTION"

If you save artifacts to "My Collection," that list is stored using your browser's own local storage, on your own device. It is never sent to any server, never shared, and never linked to you personally. Clearing your browser's site data for this site removes it completely.

ADMIN DASHBOARD

The admin dashboard (used only by the site's developer/maintainer) uses a token and password stored in the browser's local or session storage to stay logged in. This is not a public feature and does not involve visitor data in any way. See the Cookie Policy for more on browser storage.

WHAT WE DON'T DO

  • No analytics or tracking scripts
  • No advertising or ad networks
  • No account creation or login for visitors
  • No selling, sharing, or transferring of any data — because none is collected from visitors in the first place

A NOTE

This policy describes the project as it currently exists. It's written plainly for a student/personal project rather than as formal legal advice — if this site is ever expanded to collect real visitor data or deployed for an actual institution, this page should be reviewed properly before that happens.
