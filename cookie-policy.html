Cookie Policy

This site does not use tracking cookies. It does use two kinds of browser storage — technically not cookies, but serving a similar "remember something locally" purpose — described below.

LOCAL STORAGE — "MY COLLECTION"

When you save an artifact to "My Collection," its ID is stored in your browser's localStorage. This stays on your device, persists between visits until you clear it, and is never transmitted to any server. It exists purely so your saved list is still there next time you open the site.

LOCAL / SESSION STORAGE — ADMIN LOGIN

The admin dashboard stores its login token and password in sessionStorage by default (cleared when the browser tab closes), or in localStorage if "Remember Me" is checked at login (persists until manually logged out or cleared). This only applies to the site's administrator — visitors browsing the museum never trigger this.

THIRD-PARTY RESOURCES

This site loads fonts from Google Fonts and a scrolling library (Lenis) from a public CDN. These are static files (fonts, code) and don't set tracking cookies as used here, though the hosting services themselves may have their own standard server logs, outside this site's control.

CLEARING STORED DATA

You can clear everything this site has stored in your browser at any time: open your browser's developer tools → Application (or Storage) tab → find this site → clear local storage and session storage. Or use your browser's general "Clear browsing data" / "Clear site data" option.
